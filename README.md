## 🌟 Overview

A modern, high-performance developer portfolio built with pure vanilla technologies. It features a cinematic 3D hardware-accelerated canvas frame sequencer, dark frosted glassmorphism, responsive drawer navigation, and smooth interactive micro-animations.

---

## ✨ Key Features

- **🎬 3D Video Frame Sequencer:** Smooth hardware-accelerated canvas animation that synchronizes with viewport scrolling using LERP easing.
- **💎 Dark Glassmorphic Design:** Deep obsidian aesthetic with crimson and golden-yellow glowing accents.
- **📱 Fully Responsive:** Handcrafted layouts optimized for Desktop, Tablet, and Mobile with custom slide-out navigation.
- **📄 Interactive Resume & Certifications:** Direct link to resume and verified AICTE AI/ML internship credentials.
- **⚡ Zero Bloat:** Pure HTML5, Vanilla CSS, and JavaScript with fast loading and high frame rates.

## 💻 Local Development

To run the website locally on your computer:

```bash
# Clone the repository
git clone https://github.com/suny-sarkar/sunysarkar-portfolio.git

# Navigate to directory
cd sunysarkar-portfolio

# Start the local server
node server.js
```

Then open your browser and visit `http://localhost:3000/`.
